# 四视图画布

双击 editor.html 可排版并浏览交付时的候选。Windows完整模式双击 start.cmd，需要Node.js 22+；也可以把保存的HTML拖到启动器上。网页资源、候选、索引和制作记录/画布数据请随目录一起保留。

点击画布或图层选择视图，底栏显示同类候选，最新在左；悬浮预览，点击替换，可撤销。点击画布外取消选择后显示当前四视图；缺图时有候选就进入候选，没有候选才打开选图。拖入卡片可替换图片；当前卡片横向拖动排序，底栏滚轮横向滚动。

拖动移动、角点等比缩放；Shift沿起点X/Y轴移动，手动回到起点24屏幕像素内再拖出可切轴。方向键微调，Delete删除，Ctrl+Z撤销。中键或空格平移、滚轮缩放、Ctrl+0适应；顶端X/Y/宽/高可输入数值。侧栏左边和底栏上边可调尺寸，双击恢复默认。

自动对齐和自动排版位于图层标题旁；排版箭头调0–20%重叠。自动结果仍需检查发尾、饰件、衣摆是否完整。保存HTML及导出固定在侧栏顶部；保存文件包含当前图片和排版。JPG品质按钮依次切换高97、超高99、极致100，PNG不受JPG品质影响。

本机去背景模型依次为BEN2·轻量优选、BiRefNet-Full·综合稳健、RMBG-2.0·发丝精细，默认Full，强度50、柔化0。模型仅点击下载图标时下载，需要Windows64位完整模式；图片不上传。下载完成后可离线使用，缓存跨目录共用，点击缓存路径复制地址。直接双击HTML可使用普通边缘连通抠底，已有透明背景默认保留。抠像后仍需检查发丝、浅色衣料和细饰。

网页手动选图、抠像及导出不会改动制作验收记录。新增候选需重新打包更新本地索引，或完整模式点击底栏刷新。候选原图及失败/旧版本保留，不因切换当前图而删除。
