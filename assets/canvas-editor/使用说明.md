# 四视图画布

双击「编辑画布.html」自动载入交付的四张设定图，可直接排版、用 Shared Sampling 去除背景、保存 HTML 和导出图片。保留同目录的「网页资源」文件夹，其中「画布数据」保存全部候选的完整图片数据，当前四张复用对应的候选数据，不需要手动导入。

Shared Sampling 在浏览器内离线运行，无需启动后端、安装 Node.js、联网或下载模型。高质量模型需要后端，Windows 双击「网页资源/后端服务.cmd」启动完整模式，需要 Node.js 22+；关闭终端或按 Ctrl+C 停止后端。也可以把保存的 HTML 拖到启动器上。图片处理在本机进行。

## 选择与排版

点击画布、图层列表或底栏缩略图选择图片；点击画布外取消选择。拖入图片可添加图层，拖入底栏已有卡片可替换图片，鼠标停在卡片上时显示「释放替换图片」，移开或结束拖放后提示消失，点击空卡片可选图。取消选择时底栏显示当前画布图片，可横向拖动排序；选中一个视图时显示全部同类候选，悬浮预览、点击替换，可撤销。缺图时点击空卡片可从该视图候选中添加，底栏滚轮横向滚动。

拖动移动、角点等比缩放；Shift 沿起点 X/Y 轴移动，回到起点附近再拖出可切轴。方向键微调，Delete 删除，Ctrl+Z 撤销。中键或空格平移、滚轮缩放、Ctrl+0 适应；顶端 X/Y/宽/高可输入数值。侧栏左边和底栏上边可调尺寸，双击恢复默认。

自动对齐和自动排版位于图层标题旁；排版箭头调 -30–20% 重叠阈值，默认0%；负值增加图片之间的间距，0%不允许轮廓交叠，正值允许对应比例的轮廓交叠。-20%到-30%时，增大间距的同时三视图整体向左移动；后视图右侧留白及三视图整体左移量等于侧视与后视相比-20%新增间距的5倍，在同一人物高度下计算，-20%时留白为0。自动排版按图片实际轮廓安排位置，调整后可查看发尾、饰件和衣摆的完整情况。

## 图层右键操作

先选中图层，再在该图层的画布范围内、对应图层列表项或底栏缩略图上右键，可使用以下操作。右键未选中的图层或空白处不会改变选择，也不会打开菜单；选中图层被其他图层遮挡的区域同样不会打开菜单。

- 去除背景：使用当前选中的方法、强度、柔化、背景色等参数。Shared Sampling 可直接使用；高质量模型未启动后端时显示提醒，未下载时只提醒，不会自动下载。
- 导出图片：下载该图层当前图片的原尺寸 PNG，保留已有透明度。
- 锁定位置：同时固定位置和尺寸。拖动、角点缩放、方向键、数值输入、排序、自动排版和画布尺寸调整都不会改变该图层的位置与尺寸。再次右键选择「解锁位置」即可调整。

锁图标显示在锁定图片的中心，带35×35 px的半透明白色模糊方形底；画布缩放低于15%时隐藏，回到15%或以上恢复显示，锁定仍然有效。图标只在编辑界面显示，不进入导出图片。保存 HTML 会保留锁定状态。

齿轮设置卡片中的「双击快速锁定/解锁图层」默认关闭；开启后，双击画布上某个图层的可见图片区域即可锁定位置和尺寸，再双击解锁。每次切换可撤销，开关随保存的HTML保留。空白处、缩放手柄、取色和带修饰键的点击不触发；图层列表名称仍可双击改名。

## 去除背景与导出

「辅助吸附」左侧的无边框齿轮在鼠标悬停时展开设置卡片，也可点击或用键盘打开。卡片使用滑动开关，字号14px，不显示小字描述。「导出时同时导出各视角图片」默认关闭；开启后点击导出，除合并图外还下载当前特写、正面、左侧面、背面的原尺寸PNG，保留透明度。其子开关「导出未处理的原始图片」默认关闭，父开关关闭时隐藏整个子开关行，开启时显示，以灰色树状连接线表示父子关系；开启子开关后，各视角改为导出处理前的原图，保留导入尺寸、文件内容和格式，不重新裁切、抠底或编码，文件名加「原始」。合并图仍按当前画布导出。包含已隐藏的视角，缺少的视角跳过，不包含候选或额外图层；单图右键导出仍只下载当前图片。两个开关随保存的HTML保留。旧项目缺少原始文件数据时，优先读取对应候选原图，否则使用项目中保留的处理前图片。

普通算法默认使用「Shared Sampling」，强度26、柔化1.5 px，无需下载模型或额外依赖。它先根据背景色和边缘连通区域自动标记前景、背景及待定边缘，再共享采样、细化透明度并去除边缘底色。强度影响自动标记，柔化只作用于最终边缘；仍可手动取色及选择清理内部同色区域。「同时去除内部同色区域」使用与「辅助吸附」相同的勾选框样式。切换选中的图片或替换图片后，背景色自动回到「自动取边缘」，不沿用上一张图手动取的颜色；悬浮候选预览、移动或缩放当前图片不会重置取色。取色点击选中图片外时提示「请点击选中图片内的背景色。」，点击透明位置时提示「这里已经透明，请选择不透明的背景。」；无效点击保留取色状态及原背景色，可继续取色。画布周围的空白区域也显示图片外提示。内部浅色材料与背景接近时需检查是否误删。计算最长边不超过1600px，结果保留原图尺寸，不透明区域保留原始像素。算法内嵌在网页中，保存的HTML单独移动后仍可离线抠图。可选择 BEN2·轻量优选、BiRefNet-Full·复杂边缘、RMBG-2.0·发丝精细；模型仅在手动点击下载图标时下载，缓存跨目录共用。下载完成后可离线使用，点击缓存路径可复制地址。直接打开HTML时普通算法可用，高质量模型选项禁用；使用高质量模型请通过后端启动器打开。

双击「去背景强度」或「边缘柔化」滑块的圆形手柄，单独恢复该参数的默认值：Shared Sampling 为强度26、柔化1.5 px；高质量模型为强度50、柔化0 px。右侧数值同步更新，双击滑轨不会复位。后台抠图期间复位只影响下一次任务。

去除背景时，底部状态栏的背景作为进度条，尺寸、字体和两侧文字保持原样。Shared Sampling 按实际完成的标记、采样和边缘细化工作推进，完成后背景恢复；模型推理无法报告百分比时显示背景流动提示。进度不写入保存的HTML。

去除背景在后台运行，不遮挡或禁用画布。计算时仍可拖动、缩放、平移、选择图层、调整参数、替换图片、撤销、保存和导出。当前任务固定使用启动时的图片、模型和参数，设置变化只影响下一次任务；同一时间运行一个抠图任务，去除背景入口暂时不可重复点击。完成后只更新启动时的目标图层，保留最新的位置、尺寸、锁定状态和当前选择，可撤销；正在进行的拖动、变换或导出结束后再应用。目标图片被替换、还原、移除或项目切换时，旧结果不再应用。

保存 HTML 包含当前图片、排版和锁定状态。JPG 品质默认99，按钮可切换97、99、100；PNG 不受 JPG 品质影响。交付的合并总览为2560×1440、白底无字的 JPG，质量99。

## 交付目录

- 目录顶层：四张设定图 PNG、合并总览 JPG、编辑画布.html、角色描述和本说明。
- 网页资源：编辑器运行文件与「画布数据」。
- 制作记录：提示词、参考、对照及制作验收记录。

默认交付不含单独的候选文件夹和候选 PNG 原图，但全部候选完整保存在「网页资源/画布数据」，可在编辑器中预览、替换和导出。直接双击 HTML 或使用后端启动器均读取这些数据，刷新候选目录也不会因缺少候选文件夹而清空已有候选。
