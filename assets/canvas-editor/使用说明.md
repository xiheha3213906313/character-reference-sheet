# 四视图画布

双击 编辑画布.html 可排版并浏览交付时的候选。Windows双击 网页资源/后端服务.cmd 在终端前台启动完整模式，需要Node.js 22+；关闭终端或按Ctrl+C停止后端服务；也可以把保存的HTML拖到启动器上。网页资源、候选、索引和制作记录/画布数据请随目录一起保留。

点击画布或图层选择视图，底栏显示同类候选，最新在左；悬浮预览，点击替换，可撤销。点击画布外取消选择后显示当前四视图；缺图时有候选就进入候选，没有候选才打开选图。拖入卡片可替换图片；当前卡片横向拖动排序，底栏滚轮横向滚动。

拖动移动、角点等比缩放；Shift沿起点X/Y轴移动，手动回到起点24屏幕像素内再拖出可切轴。方向键微调，Delete删除，Ctrl+Z撤销。中键或空格平移、滚轮缩放、Ctrl+0适应；顶端X/Y/宽/高可输入数值。侧栏左边和底栏上边可调尺寸，双击恢复默认。

自动对齐和自动排版位于图层标题旁；排版箭头调0–20%重叠阈值。排版依据透明图片的实际轮廓寻找能放入的最大高度：0%避开重叠，更高阈值允许少量轮廓重叠以增加可用高度；拖动实时调整人物间距，能放大时同步改变高度；达到高度上限时保留高度并显示提示。原本已能满高放下时，高度变化会很小或保持满高；不透明图片按矩形避让。自动结果仍需检查发尾、饰件、衣摆是否完整。保存HTML及导出固定在侧栏顶部；保存文件包含当前图片和排版。JPG品质按钮依次切换高97、超高99、极致100，PNG不受JPG品质影响。

本机去背景模型依次为BEN2·轻量优选、BiRefNet-Full·综合稳健、RMBG-2.0·发丝精细，默认Full，强度50、柔化0。模型仅点击下载图标时下载，需要Windows64位完整模式；图片不上传。下载完成后可离线使用，缓存跨目录共用，点击缓存路径复制地址。直接HTML未连接后端时整个抠图区域禁用并变灰；连接后可使用普通算法及模型，断开后自动恢复禁用状态。已有透明背景默认保留。抠像后仍需检查发丝、浅色衣料和细饰。

网页手动选图、抠像及导出不会改动制作验收记录。新增候选需重新打包更新本地索引，或完整模式点击底栏刷新。候选原图及失败/旧版本保留，不因切换当前图而删除。
