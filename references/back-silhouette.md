# 背面镜像剪影辅助

用于用户要求的剪影试验，或背面缺少参考、共享外形及长部件投影容易漂移时。先判断前后姿态、相机与主要轮廓是否可比，再选择采用。它是外形参考，不是完整三维约束；不保证改善，也不默认增加两次生成。

## 先确认正面与结构

常规制作使用当前已验收正面；正面已有尾巴数量、断口或轮廓错误时，先依原图纠正，不能镜像传播错误。用户限定的实验可使用仅针对本次目标核对的正面，记录核对范围并保留候选状态，不能借此认证整套。

先按 [空间结构](spatial-logic.md) 明确部件数量、固定点/根部、路径、自由末端与遮挡者。尤其是单根尾巴：两侧露出弧段可能来自同一根长尾，不能数弧段认成双尾，不能把回弯中段画成第二自由尾尖，也不能删除有效弧段来消除数量错误。看不见的连接采用与证据相容的明确方案；正面、背面、侧面沿用同一方案。

## 准备与镜像

1. 从有效正面的真实Alpha提取二值剪影，保留原生画布、位置、尺寸及所有可见部件。默认Alpha>4为黑色主体，其余为白色背景；必要时调整阈值，记录并实际查看细发、毛尾、薄纱等是否被遗漏。RGBA文件名或模式不证明抠像有效；需看Alpha及剪影。
2. 沿竖直中轴左右镜像：`(x, y) → (宽度−1−x, y)`。人物仍头上脚下，纵坐标不变。不要上下翻转、旋转180度、独立拉伸、拼补尾巴或重新设计轮廓。
3. 实际打开正面、正面剪影及镜像剪影，确认方向、外形和细部保留。镜像映射的是前后可比投影，真实视角、姿态与遮挡差异允许合理变化，不能强迫后方部件完全逐像素吻合。

透明输入可用 `scripts/mirror_silhouette.py`（依赖Pillow）：

```sh
python scripts/mirror_silhouette.py --source "正面.png" --output-dir "制作记录/背面剪影"
```

脚本输出 `front-silhouette.png`、`back-silhouette.png` 与 `silhouette-record.json`；保存来源哈希、原生尺寸、Alpha范围、阈值、变换及输出哈希，拒绝覆盖同名文件。它不分割背景、不判定造型是否正确、不调用图像生成。

只有不透明正面时，先按 [抠像与背景](background-and-delivery.md) 得到并实际核验分割结果，再提取剪影。不能按白色RGB直接删背景，白发、白袍和半透明边缘也可能是人物；没有可靠分割就不用这条辅助路径。提取和镜像不改变源图。若工具不接受透明输入，按其真实能力准备参考；黑白剪影本身可作为普通RGB图片。

## 输入分工与提示词

保留有效彩色正面和本轮必要的原始后/侧/部位证据；镜像剪影作为附加输入，只负责共享投影外形。按实际输入顺序保存用途与哈希，调用文本仍遵循 [提示词构建](prompt-construction.md)。示例用途按当前角色替换：

```text
附加黑白图是正确正面沿竖直中轴左右镜像的剪影，人物头上脚下。它仅作背面共享外轮廓的位置与比例参考，尽量保持可比的头饰、发长、肩袖、衣摆和长部件外弧。
生成严格180度背面，重新判断后脑、背片、前饰的远侧位置及部件的连接、近远与遮挡；不复制正面的胸腹开口或内部布局。把剪影还原为同角色正确的背面材料，不输出黑色剪影、文字或辅助标记。
```

尾部数量、根部、转弯路径、末端和遮挡的关键约束另按当前证据写清楚，不指望黑色轮廓表达这些关系。工具只有参考图能力时，这只是软参考；没有硬蒙版、ControlNet、权重或种子参数就不能宣称已使用这些控制。工具提供专门控制时按其真实能力使用并记录。

## 验收与实验边界

常规验收按 [对照制作与查看](visual-verification.md)：按独立身体锚点统一等比尺度与高度，分别检查镜像目标与背面的外形、原图与候选的设计，以及正—背—侧的结构关系。不可分别拉伸或按待检尾尖对齐来掩盖误差。检查尾部原生局部的根、可见弧段、自由末端、进入/离开遮挡处；外形接近仍可能分叉、断开或把前后覆盖复制错。

可用外轮廓行包络重合率、左右边界偏差辅助定位漂移，但不是质量分、合格率或隐藏连接证明；完整前景重合率也受内部遮挡影响。不能仅因指标提高批准候选，也不设通用数值通过线。背面必须同时满足自身质量、原始设计与空间关系。

用户要求比较方法时，可做A/B：共用同一正面、原始证据、结构方案、构图、光照、背景和其他提示；B仅追加镜像剪影及限定用途。分别从相同有效上游生成，结果不能互作输入，保存真实调用。各条件仅一张、种子不可控时只说明本轮观察，不能当作稳定改进证明。本次两类角色试验一组外形明显改善、一组未改善，因此保留条件性使用；失败后的修复与停止仍按 [验收与返工](quality-and-revision.md)。

仅生成、不验证的试跑遵守用户范围，跳过结果对照及验收，保存未验收候选；不得把剪影辅助成功调用当成验收通过。技能更新本身不触发图像生成。


## 结构路线与层级补充

仅凭外形不能稳定表达连接、归属或遮挡时，按 [结构引导](structure-guidance.md) 从同一几何定义生成实体路线与目标背面层级。镜像来源的遮挡缺口不等于目标部件的真实缺口；新视角露出的部位按 [部件补全](component-completion.md) 补出结构与材料。不要直接把问题来源的可见段当成完整部件，也不要只加一段无装饰细线闭合原有宽厚构件。
