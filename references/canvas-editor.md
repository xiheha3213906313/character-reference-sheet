# 网页编辑器

需要释放、使用或维护编辑器时阅读。可复制资源在 `assets/canvas-editor/`，释放步骤和目录约定见 [候选与网页交付](candidate-delivery.md)。普通角色制作复用这份现成包，不重新开发网页。

## 打开与保存

- 双击 `编辑画布.html` 使用 `网页资源/交付索引.js` 自动载入当前四张；同类候选按需读取 `制作记录/画布数据/`，不请求本地目录权限。它读取打包快照；新增候选后重新打包更新快照。
- Windows双击 `网页资源/后端服务.cmd` 在终端前台启动服务，需要Node.js 22+；关闭此终端或按Ctrl+C停止服务和模型会话，不留独立后台服务；也可把保存的HTML拖到启动器上。服务仅监听本机、读取已登记目录的固定四图和规范候选，拒绝越界或链接路径。点底栏刷新可读新增规范候选，无记录的标未验收。
- 保存HTML内嵌当前图片、背景和排版，单独移动后仍能编辑当前图；候选浏览需要保留整套目录。整目录搬移后入口与资源使用相对路径。
- 顶栏已移除，保存与导出固定在侧栏最上方。默认2560×1440白画布，另有1920×1080、3200×1800、3840×2160；默认侧栏264px、候选底栏167px，可拖边缘调整、双击恢复，首选尺寸存入浏览器与项目。
- 正式四图和总览默认PNG。网页交互导出默认JPG，高97、超高99、极致100依次点击循环；档位随项目保存，PNG不受该档位影响。选框、辅助线与临时预览不进入导出。网页保存/导出不回写制作验收记录。

## 选图与排版

点击画布/图层选择；Shift/Ctrl加点击多选，空白拖动框选，Ctrl+A选全部可见层。拖动移动、角点等比缩放，变换框与角点可在画布外显示操作，图片及导出仍裁于画布。方向键1px、Shift10px；Delete/Backspace删除，可撤销。工具栏X/Y/宽/高作用于选中组，项目名右侧分隔线可调宽，最大到完整文字，不显示悬浮说明。

Shift拖动两轴都基于本次拖动起点；需手动回到起点24屏幕像素内，再沿另一轴拖出才能切轴，远处转向不跳回。关闭吸附仍锁轴，吸附不改变锁定轴。中键或空格平移，滚轮以鼠标为中心缩放，Ctrl+0适应；放大隐藏工作区滚动条。Ctrl+Z/Ctrl+Shift+Z撤销重做，Esc取消拖动。

选中视图后底栏显示同类候选，编号降序、最新最左。悬浮/聚焦仅临时预览，离开恢复；点击替换保留图层高度与中心，可撤销。取消选择后显示当前四视图和额外图，缺视图保留空槽：有候选时点击空槽进入候选，无候选才选文件。拖图片到卡片替换；多张先替换目标再填后续空槽，多余作为额外图。当前卡片横向拖动排序同步画布横向位置，保留大小与纵向位置，不留原处残影；滚轮横向滚动。

自动对齐在左，自动排版在右。排版箭头展开0–20%重叠阈值，默认10%；高度依据当前透明图片逐行的实际可见轮廓自适应搜索，不再用整体图片宽高比或旧10%/20%高度拟合端点。0%求不重叠时可放入的最大高度，其他值允许每行最多重叠较窄可见轮廓宽度的对应比例；每次都重新求可用最大高度，并按当前阈值计算横向间距；达到高度上限后仍响应间距调整，不能把所有阈值替换成同一个最小重叠布局。弹窗显示当前人物高度，达上限时明确提示。高度上限仍为画布的97.5%，特写约占宽度三分之一并贴左下，三视图等比、同高、底部对齐且整体右对齐。原本已能满高放下时高度范围可以很窄或相同，不能为制造变化强行缩小；宽袖、裙摆或额外图占据更多空间时才需明显降低高度。透明轮廓按Alpha大于6计算，少量边缘余量保护发丝和薄纱；不透明图片保留矩形避让。滑块实时排版，一次拖动一次撤销。参数只控制几何容许量，不能保证关键饰件或结构未被遮挡，仍按总览规则看图。

## 背景处理

未连接后端时整个抠图区域禁用并变灰，连接后启用，终端关闭后自动禁用。已有有效Alpha默认保留，避免二次识别误删装饰。纯色图可用边缘连通算法，强度26、柔化1.5；白发白衣和闭合背景空洞必须检查。高质量模型按体积排序：

| 选项 | 输入/体积 | 用途与预设 |
|---|---|---|
| BEN2 · 轻量优选 | 1024px，FP16，约209MB | 较小模型选项，强度50、柔化0 |
| BiRefNet-Full · 综合稳健 | 1024px，FP32，约928MB | 默认模型，强度50、柔化0 |
| RMBG-2.0 · 发丝精细 | 1024px，FP32，约977MB | 发丝/毛发可重点比较，强度50、柔化0 |

既有角色测试支持保留这三项，不保证新图片一律最好；按发丝、浅色材料、配饰完整性与空洞实际检查。浏览器只向同机服务提交像素；Windows64位ONNX Runtime/DirectML推理，GPU不可用时回退CPU。模型切换和空闲60秒释放会话。

仅点击下载图标才下载所选权重与固定运行时；取消停止重试，大小和SHA-256匹配才记为完整缓存，原站失败可重试同版本镜像。缓存跨人物共用，Windows默认 `%TEMP%/CharacterSheetCanvas/cache`，地址点击复制；启动器状态在 `%LOCALAPPDATA%/CharacterSheetCanvas`。技能与交付包不含权重/原生运行库；直接HTML不能调用本机模型，完整下载后启动器模式可离线使用，清理缓存后需重新下载。

处理结果另存候选并记录原始输入、模型/参数和输出哈希；检查主体内部、细发丝、细饰、薄纱和深浅底边缘，再更新验收与当前版本。不把手动抠像或下载完成当作质量认证。

## 维护边界

网页使用说明放在资源包内，流程只链接此参考。修改网页或运行文件后更新 `网页资源/release.json` 中实际哈希，运行释放/打包检查后再同步技能。通用 `编辑画布.html` 的 `initial-project` 与 `demo-data` 保持 `null`，真实人物数据由交付索引加载。模型与下载校验以 `网页资源/hub.mjs` 为准；权重、测试图、缓存、依赖或个人绝对路径不塞进技能。
