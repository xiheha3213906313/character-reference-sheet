# 交付接口

仅四阶段选定后读取。入口与公共参数见[制作接口](production-api.md)。普通制作不读打包、编辑器或脚本源码。

## deliver

直接调用deliver。脚本复用现成编辑器，整理四张当前PNG、全部真实候选画布数据、2560×1440无字JPG、角色描述和制作记录；默认搜索无交叠布局，不要求模型逐对调整重叠。制作区原生候选保留，交付目录不重复放候选PNG文件夹。

返回两张需实际查看的图片和`inspection_config_file`绝对路径。只查看返回的images，直接编辑该文件的inspection，不猜读总览旁录或不存在的交付清单，填写实际查看项、两项观察及pass/fail/pending；不要重抄binding或layout。之后直接执行返回的submit_command；它使用技能入口和配置的绝对路径，避免误从当前目录调用不存在的sheet_flow.ps1。模板初始pending且无查看记录，文件检查不会自动生成视觉通过。

脚本保存预览的实际layout；即使简查提交只带inspection，也自动复用它。配置文件放在制作记录/交付接口即可，位置不会改变绑定，添加或修改简查记录不使图片失效。只有所选阶段版本、角色信息或显式layout变化才需重新预览和实际看图；过时简查不能直接批准新版本。特殊排版确有需要才读[总览规范](background-and-delivery.md#四视图总览)，提交layout后查看新预览。

简查通过后自动复制到素材目录的`角色名称_描述性造型`新目录并核对最终文件。同名旧目录存在时脚本在同一素材目录选择带版本后缀的新目录，不覆盖旧交付；预览准备时确定目标，后续重试沿用该目标。用户另定位置只在start凭用户原话绑定。deliver只接受inspection和可选layout；destination、destination_reason或其他临时目的地字段直接拒绝。fail/pending不复制、不宣称完成。

复制使用逐文件临时写入、哈希核对和原子替换；中断标记绑定本次包与同一目的地。PermissionError返回request_file_access、失败路径、可直接执行的retry_command和script_source_required:false。制作模型使用当前工具的权限申请机制（本地exec_command为require_escalated）原样执行该命令；获准后继续同一目标的部分复制，不改配置，不重生图，不擅自改到outputs。确实遭权限拒绝才如实报告尚未交付，不能把工作副本当最终交付入口。续传仅接纳本次已核对文件，未知或被改变的目标文件保留并报错，不覆盖、不删除。记录和元数据在复制前一次生成，不在最终目录反复修同一文件。

返回next_action:done表示复制与最终核对已完成，直接使用destination/preview_file/editor_file并停止，不重复deliver、列目录或自行再复制一份outputs。只有最终目录核对成功才在制作区记录complete；ready_to_copy仍未交付。文件完整性、记录一致性和视觉状态分别报告。
