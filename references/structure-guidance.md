# 剪影、结构路线与背面层级引导

用于缺少背面证据、长部件反复断开或部件归属漂移。普通换视角能稳定生成时无需增加全部引导，也不强制做对照实验。参考图按当前工具真实能力使用；普通多图参考是软引导，不承诺逐像素锁定或未提供的 ControlNet、权重、种子。本结构控制流程的最终生图与局部修改使用闭源图像模型，脚本只准备参考与记录，不下载或部署本地生图模型；用户后续明确另选工具时按其要求和真实能力执行。

## 准备相互一致的依据

先从本角色正、侧和细节确认部件数量、归属、连接与材料，区分原图确证、用户指定、已采用推断和未知。正面的两处外露弧不能证明两根尾巴；镜像剪影也不能证明隐藏连接。常规制作先修正不合格上游。用户明确要求用问题原图做实验时，可保留其有效设计区域并隔离问题部位，标记为试验输入，不把它变成合格上游。

- **身份与设计 A**：有效正面/原图，保留完整设计上下文。
- **轮廓与结构 B**：正面 Alpha 沿竖直中轴左右镜像，保持头上脚下；同一目标画布上补入经判断的真实部件占据区域。细长部件用有宽度、根部和末端的连续实体带；披衣、翅片等用面积与必要骨架。对比必须清楚，可用灰主体加深色部件，颜色不是固定规则。多个真部件分别建模，不能为了连续而连接原本独立的部件。空心饰件保留孔洞。
- **连接与材质 C**：选原始清楚局部，不借错误候选替换材料。透明薄膜、薄纱需要时保留原始 Alpha，并给同一局部浅底/深底外观，注明底色仅供观察；最终不复制演示底色。
- **目标背面层级 D**：结合侧面证据和已采用背面设计重建相对远近；背景黑，较亮前景更靠近背面观察者。正面深度检测可作为可选诊断，不能直接把全图反相当成背面深度。改变相机方向会改变可见面、连接投影及遮挡，需要按部件重判。D 是层级假设，不是测量得到的真实背面三维深度，也不表示透明度。

B/D 使用同一几何定义，不分别手改成互相矛盾的路线。相交处明确谁遮谁；同一部件不同段有不同遮挡时拆成同属一个部件的区段，不能把数量改掉。实体路线完整，合理遮挡单独说明，不用虚线让模型猜补连接。遮挡解除后的饰件按 [部件补全](component-completion.md) 同时补出截面、纹样和附属构造；环的宽厚结构、孔洞和齿刺等应进入同一完整方案，不能只在层级图画一条无设计的细弧。

## 生成与检查

完整关键部件按 [首次生成前的补全](component-completion.md#首次生成前确定完整方案) 前置到本次正面制作，后续各视图共享完整设计及本套光色，优先直接生成。轮廓/层级参考仅包含一套该部件，不能在原有部件轮廓上再叠另一个；实际查看并拒绝残留旧轮廓。独立部件仅传结构时明确限定用途，角色材料本色及统一光照以有效角色依据为准。

提示词描述目标已经正确的状态：视角、参考分工、部件归属与数量、连续路线的大致走势、必要遮挡和材料。允许自然小幅位置变化；根部、数量、连接拓扑和关键层次比逐像素位置更重要。只补当前存在的歧义，避免堆叠故障叙述。示例：“后背只有一根连续黑色毛尾，从骶部长出，沿 B 的实体带大致走向；尾根可被长发遮住，下方横向扫过袍摆的部分可见。”具体目标随角色改变。

核验全部目标部件的数量、根部/承托对象、分支或末端、连续性、整体走势与主要遮挡，并同时检查原始设计、材料、比例和未修改区域。尾巴根部被合理遮住时记录不可见，不能声称已经验证其隐藏解剖。金属杆等刚性饰件另查原始长度和节点，不因轨迹相近就放行改款。透明输出实际看浅底、深底及必要原生局部；RGBA 格式或背景 Alpha=0 不证明膜面半透明。脚本统计只诊断，不自动通过。

连接拓扑持续错误时，回到有效原图重新生成，尝试更清楚的实体占据表达和更简洁的目标提示词。拓扑错误的整张候选容易把错误留在编辑中，不反复补接。主体结构已正确、只有局部遮挡/材料错时，优先纠正参考后从可靠依据直接生成；确需编辑时才以未编辑基线尝试一至两次独立闭源编辑；辅助候选仅能采用已核验的有效局部，裁除其问题部位并记录局部用途。编辑后复检全图和目标外区域；重复失败按现有返工规则换策略或停止并说明限制，禁止把编辑结果接成编辑链。

批量时共享规则与脚本，不共享角色结构推断。每个角色先准备可复用结构定义及明确验收项，少量独立候选验证后继续；用户要求实验时可记录重复样本，普通制作不强制追加固定数量。保存输入顺序、各图职责/哈希、实际提示词、原生结果、编辑基线、取消调用和验收结论。全图实验通过不等于整套四视图已经通过。

## 脚本边界与接口

`scripts/prepare_structure_guides.py` 只渲染经核对的结构 JSON，不自动推断解剖，不调用生成模型，不修改成图。Pillow 可用时执行：

```text
python scripts/prepare_structure_guides.py structure.json --output guides_v1
```

JSON `schema_version:1`；`source` 和 mask 路径相对 JSON 所在目录，`canvas:[w,h]` 与已配准来源一致；`mirror_x:true` 只镜像来源 Alpha。目标坐标、已配准 mask 不再次镜像。默认 Alpha 阈值4，改变阈值记录理由；无有效 Alpha 的来源须提供人工确认的 mask。`body_mask` 可指定 `{"kind":"mask","file":"body.png"}`，白色代表主体，必须已在目标视角。脚本拒绝覆盖旧版本目录。

`parts` 每项含：`id`、`shape`、`depth_value`、可选 `guide_gray`/`show_in_guide`、`nearer_than:[part_id]`，及保留在旁录的 `owner`、`expected_count`、`root`、`tip`、`material`、`evidence`、`visibility`。根部等语义字段由执行者核对，脚本不能据此证明连接正确。

`shape` 支持：

- `path`：`points:[[x,y],...]`，目标画布归一化坐标；`width_fraction` 以画布宽度为单位，或 `width_profile:[[0,w0],...,[1,w1]]`。连续实体带，不输出虚线。
- `polygon`：`points`；`ellipse`：`box:[x0,y0,x1,y1]`；`annulus`：相同 `box` 加 `width_fraction`，表示保留中央孔洞的闭合环带；`mask`：与画布等大的灰度占据 mask。复杂孔洞/变截面/披衣可以使用已核对 mask，路径点不得误连不同部件。放射件等分别建模，不自动猜数量或等距复制。

`depth_value:1..255` 只表示相对层级；局部 `nearer_than` 用于检查数值矛盾，不推断真实遮挡。循环相互遮挡须拆区段后重新定义。材质 Alpha 另由参考与验收处理，不写进深度值。输出 `silhouette_structure.png`、`rear_layers.png`、主体 mask 和带哈希的旁录，状态初始为 `not_evaluated`。需要先实际看生成的 B/D；脚本成功不能替代视觉验收。
