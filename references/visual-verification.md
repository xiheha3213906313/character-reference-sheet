# 对照制作与查看

制作端简单自评只看参考—候选拼图；以下原生、缩小和背景要求用于完整复核。普通制作由[制作接口](production-api.md)在receive时一次准备所有证据，复核者直接查看，不重新生成。按当前组需要看图，已看清的原文件不重复打开；原生局部依据主体范围及头、胸腰、裙摆、腿鞋的位置取区，过滤空白，不遍历画布网格。部位比例只是定位辅助，不能证明部位已识别或视觉合格；必要时一次补证修正。背景只看alpha_compare一次，不再开light/dark。

对照用于判断差异，脚本排版成功不等于视觉通过。单看候选用于查自身问题，通过结论还需有效参考及相关视图证据。

本文件用于用户要求的评审、常规制作的首张及最终选中的新增候选复核。落选追加候选只排序，不强制生成全部证据或逐项验收。用户明确要求只生成、不验证时，保存未验收候选即可，不制作这些对照或自行追加返工。复核模式及最小证据包见 [阶段复核](review-workflow.md)。

## 实际操作

1. 固定原始证据、合格上游、未修改G0和当前候选及哈希；对照文件放本套的 `制作记录/对照/`，不混入当前四图或候选。
2. 先打开流程助手自动拼合的参考—候选对照，再看候选整幅及关键否决项；明确失败可停止剩余完整检查，未查项保持待核实。没有明确失败再按组查，按目的选全图/局部及可比尺度。裁切保留轮廓、连接和遮挡上下文，不只挑最像的部分。
3. 使用任务包里的紧凑并排对照，检查排版尺度和可见范围，实际打开PNG。默认对照可用于整体，不合适时用register的comparisons裁切配置补对应部位；原生质量另看native局部，不能把缩小拼图当清晰度证据。工具自动缩图导致细节不可辨时拆分；仍有不确定或冲突只补一次更适合的原生局部/对照，仍无法判断保持待核实，不自动重生成。
4. 看完当前组就记录参考事实、候选表现、证据位置、方法及 `pass/fail/pending`，明确实际 `viewed_evidence_ids`，再看下一组。原生与缩小质量分别检查；头发清晰度和面部脏污分别写观察，不能只记录文件尺寸、Alpha和整体好看。未打开或未核实仍为待核对。脚本不能代填看过或通过。
5. 任一来源版本变化后刷新受影响对照并复检；旧图不能证明新版本通过。整张并排图已实际看过，可以引用其中清楚可见的面板，不必再逐个打开所有来源；只登记已看的对照id，不把其中原文件全部写成已打开。

整体和细节都实际看，清晰度按部位占用的实际像素判断。头发不逐根追查，左右画边截断长发、顶部飞丝触边和少量彩边可以接受；头顶主体与重要头饰仍须完整，明显模糊或糊成一片才失败。第二次交回原子代理仍查看上次指出的细节，饰品位置、长度等按设计合理性判断：就当这样设计，只要关系合理直接通过；只拒绝明显不合理、完全不能接受的程度。

视角改变或修正遮挡后，按 [部件补全](component-completion.md) 单独检查新露出区域：与有效可见段的截面宽度、边界、纹样及附属件是否延续；独有装饰是否被误复制。检查完整对象及接续处，不只看这次补出的线段。遮挡改正确但新露出区域被简化或变款时仍不通过。

对照图只保留必要短标签，如“参考/G0/E1/候选”“正面/左侧/背面”，按长度问题需要加少量细线/数值；解释、路径、倍率、锚点和结论另记。对照文件可以多，每张聚焦一处关系或一组版本，通常只放判断该问题所需的两三对象；不同部件或问题拆图依次查看，不把所有角度、尺度、来源和局部塞进一张。同一版本的相同部位不重复占栏，当前就是G0时只保留一栏，不能制造无信息对比。交付总览是另一用途，按 [总览规则](background-and-delivery.md#四视图总览) 无文字排版。

## 按目的选方法

| 目的 | 制作和判断方法 |
|---|---|
| 身份/设计保真、比例或几何变化 | 对应全图或局部并排，按独立对象/身体锚点匹配主体尺度；比较真实轮廓、比例、配置与连接 |
| 发丝、表面、纹理清晰度与劣化 | 原生1:1裁切或单栏原生局部；必要时另做缩小的同尺度结构对照 |
| 脏点、斑驳与整体表面 | 当前与固定基线等比缩小到相同主体显示尺度，保留原色；回查原生及原图 |
| 模糊有效细节与污染的区分 | 原始疑点、可靠对应/连续区域和候选的原生局部分别看基底与图案，另看缩小表面；按 [判别依据](surface-detail-diagnosis.md) 写保留/排除/未知，不能以同一坏贴图多视角一致确证 |
| 多视图连接、层次与遮挡 | 同一部件的正/侧/背局部，保留连接点和承托/遮挡对象，整体关系另看全身 |
| 长度、位置或末端高度 | 用独立身体锚点统一尺度及高度，必要时少量共用细线；不按待检末端对齐 |
| 本色/画风与光照、表情 | 本色、材料及画风与有效原图比；柔光和表情状态与指定呈现比。分别做适用对照，不借另一角色示例检查当前身份；不先调色、锐化或增强 |
| 特写构图 | 看候选整幅，按 [位置与占比](presentation.md#特写位置与占比) 判断头部是否为主体、身体占比与镜头是否明显偏下；面部差不多居中即可，不测精确中心。用户另给镜头样例时可整幅并排，不裁切重新居中掩盖问题 |
| 头部姿态、注视与表情 | 依 [呈现验收](presentation.md#呈现验收) 分别判断。头态看完整头颈；注视必要时单看双眼原生局部并回看整脸，结合虹膜/瞳孔位置、眼白分布与眼型，不只凭上眼睑遮住虹膜。来源表情/姿态不作为默认目标，闭口或近正面不能代替这些检查 |

**画布等大不等于主体等大。** 默认按头部或身体大致相近的尺度并排，保留颈根、锁骨、肩胸等适用锚点，用眼判断关系可接受即可；小偏移、透视及姿态差异不需要精确测量。仅当大幅错位存在争议且会改变结论时，才标独立锚点、记录实际坐标并等比缩小作辅助，不拉伸/扭曲来凑一致，不把锚点或端点精确重合作为合格条件。原生清晰度局部单看即可。

原生对照回答像素细节问题，不自动回答比例/形体是否一致；结构对齐也不取代原生质量。原生局部和实际交付显示都要看；不能只凭小图里尚有发束走向，掩盖正常显示中的明显模糊。姿态、透视和新视角有真实投影差异，无法精确对齐时说明范围和误差，改用可解释的轮廓/连接证据，不能用不合适的对照放行。用户已指出的失败区域作为本次修复目标，旧自评或新代理的相反意见不是撤销它的理由。

同视角、同姿态且独立锚点可靠时可用切换/叠加辅助位置检查，仍保留原色并排和原生检查；不同视角不叠加判断结构。辅助线不遮关键细节，不用于材料/光色对照。

## 各阶段证据

| 阶段 | 必查对照 |
|---|---|
| 特写 | 原始身份与候选；发型/饰件、画面内服装及输入的细节局部；指定光照/表情、整幅构图；原生与缩小表面 |
| 正面 | 原始造型全图；本套合格特写与正面脸部按头部尺度匹配；关键服装材料/层次、连接与原生质量；缩小表面 |
| 背面 | 后方原图—候选设计对照，正面剪影—候选比例轮廓；必要已采用方案；原生与缩小质量。自然遮挡只查可见连接，不要求看穿头发 |
| 侧面/终验 | 正—侧—背整体与关键部件局部；三组关系及共同结构；侧面原生与缩小质量。终验复用四张仍有效的阶段检查，仅补受影响项及总览排版 |
| 编辑/重生成 | 原始/合格依据、固定G0和当前结果的全图与适用局部；目标、关键未修改区域及受影响角度 |

按照任务实际内容分图检查主体内部、外轮廓、对象边界与连接，不能只看脸或本次修点。若材料占较大面积则分段覆盖，记录具体可辨边界/层次，不能用“清楚无脏块”代替全部质量。每张看完再写当前观察，不根据提示词预填通过。

## 输入细节逐项对照

从本次实际调用的输入列表及 `图片选用文档.md` 提取细节用途，列明每张有效细节图片提供的部位/事实，以及它在候选中的对应区域；原生裁切同时关联原始文件与范围。不能只检查主参考或最显眼的大部件，不能把“传过细节图”当作“生成正确”。还要回查覆盖表：应该输入但本轮遗漏的关键证据，补看后照样检验，记录输入遗漏。

对各项实际制作并打开 **细节参考—候选对应部位** 的紧凑对照。按问题选择方法：纹样的主形、内部构件、轮廓、相对大小/方向及布置用可比主体尺度；发丝、材料组织、边缘和劣化看原生局部；穿戴位置、连接和叠层保留承托对象与身体锚点，必要时再与其他视图对照。必要原生与结构比较分图完成，不把所有部位塞一张。标签只用“细节参考/候选”等短语，路径和结论另记。

每项写参考与候选的实际细节、证据和结论。首次比较是否大致符合；返修仍看细节，但允许合理设计变化，记录为什么可接受，不因位置或长度没有精确复原而拒绝。明显糊成片、穿戴/连接一眼不合理等仍检查。特写服装保留原图颈根、锁骨、肩胸上下文，本应画外不算缺件，明显大幅抬高才失败。

一个细节输入提供多个关键事实时分别覆盖，相同事实可合并适用对照并保留来源。未出现在本视图或合理遮挡写明原因；长发自然出画、本应在特写下缘外的衣服不算缺失。第二次复核的部件位置/长度偏差只在明显不合理时拒绝，合理即可接受。无法辨认关键关系只补一次证据，仍无法确认则待核对；达到上限另走选优继续，不伪造视觉通过。

## 光色与纯白背景检查

原色对照主体肤色、发色、材料本色与原画风，并将曝光、对比、冷暖、阴影层次对照 [指定呈现](presentation.md)。默认柔光不要求复制原素材场景光；检查的是候选是否符合选定柔光，以及角色配色、材料、画风是否被误改。尤其检查白底是否在目标光照之外冲淡阴影、漂白主体或增加白色轮廓光。背景合格不抵消主体呈现漂移。同套各视图及新补部件的光色另与共同基准做原色对照：色相、饱和度、曝光、高光与阴影响应是否协调；同材质饰件可作局部锚点，保留真实材质和朝向差异。不得先调色再比较、以相同背景或金属都呈黄色判通过；结构补全却显著更艳、更亮或像独立打光的贴片仍失败。

生成背景分支按 [背景优先级](background-and-delivery.md#生成背景优先级)。透明版实际查看浅底、深底的完整主体和必要原生局部，核查全透明空白、不透明部位、细发丝/长饰件、轮廓白边与薄纱叠层；不能用Alpha最小值为0、文件RGBA或白底总览掩盖错误。抠像候选按 [抠像检查](background-and-delivery.md#非透明图片抠像) 核验，记录真实Alpha来源，不冒充模型直接输出。

RGB降级版按视觉接近中性白且大致均匀验收；253/254等轻微偏差允许，明显灰米/彩底、明显渐变或场景阴影仍检查。从远离主体、发丝和薄纱的真实空白抽样，记录实际RGB，不能抄提示词或用总览白画布证明原图白底。记录 `background_policy.mode:"near_white_rgb_fallback"` 及实际输出限制；用户明确严格纯白时才用 `exact_white`。脚本近白抽样的各通道至少245、通道差不超过8仅作辅助，视觉判断仍必需。

Alpha输入不支持时可用 `scripts/export_white_background.py` 将已有、已检查的Alpha临时合成白底RGB，供下游参考或诊断，放制作记录；不是重新生成、不是另一套默认交付。保持来源和输出哈希，完全不透明主体像素不改；不能将导出成功当视觉通过。没有此运行环境使用允许的等价合成能力。

流程助手自动生成comparison并排图及alpha_compare深浅底拼图，旁录绑定来源、裁切、实际倍率、排版位置和输出哈希。看alpha_compare一张即可覆盖两种背景；看清后才确认空白采样候选，脚本读取RGB/Alpha。哈希和像素读取由脚本完成，复核代理不运行机械检查。

## 对照脚本

有Python/Pillow时使用 `scripts/compose_review.py`，没有则用当前允许的排版能力做等价证据。它只裁切、向下等比缩放、对齐与排版，不自动识别锚点、判断款式或做视觉验收。图像实际检查和状态由执行者负责。

```bash
python "<技能目录>/scripts/compose_review.py" compare "<对照配置.json>" --output "<对照.png>"
```

配置包含 `column_width` 和 `rows`；每行 `panels` 的 `image` 为真实来源，`crop` 可选，`scale` 为0到1的等比倍率，`label` 是可选短标签。几何对照先定尺度，再给各栏原图坐标的 `anchor_y`，同一行全部填写或全部省略；细节原生裁切用scale=1。行内可选 `guides:[{"offset":0,"label":"0"}]`，offset是相对共同锚线的显示像素。无锚点时相对图片区域顶部，不能据此测不同尺度物体长度。

例如局部原生并排：

```json
{"column_width":600,"rows":[{"panels":[
  {"label":"参考","image":"reference.png","crop":[100,100,600,500],"scale":1},
  {"label":"候选","image":"candidate.png","crop":[150,200,650,600],"scale":1}
]}]}
```

示例坐标不是通用裁切，必须按真实文件更换；此配置未声明几何对齐。输出旁录保存哈希、裁切、实际倍率与排版位置，`not_evaluated` 表示还没有视觉通过依据；实际查看后在 [验收记录](stage-review.md) 写判断。全局/行标题只进旁录，不绘报告文字。

## 四视图交付预览

按 [四视图总览](background-and-delivery.md#四视图总览) 使用2560×1440无字白画布，特写贴左下、最高图层、实际显示宽度至少三分之一，三视图在右侧保持较大且完整的呈现；实际打开总览，并检查相邻视图的全部轮廓，尤其是发尾、饰件、薄纱、裙层与拖尾，不能只检查脸、手脚和位置数字。需要时做原单图局部与总览的紧凑对照，确认排版没有遮掉细节。透明单图在总览中合成到白画布，不另交付白底单图。最终只展示总览，名称及当前来源核对见 [文件与最终发送](background-and-delivery.md#文件与最终发送)。
